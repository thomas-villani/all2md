- DOCX numbering now prints the labels Word shows. A numbered heading reads `## 1.1 Definitions` or `# Article I Definitions` instead of losing its number. A clause labelled `(a)`, `1.1` or `03)`, which Markdown list syntax cannot write, becomes a paragraph starting with that label, while plain `1.` lists stay Markdown lists. Letter, Roman, zero-padded and legal (`w:isLgl`) numbering are all written as Word prints them. A list followed directly by a heading is no longer emitted after the heading. The Markdown renderer now escapes a paragraph that begins like an ordered list marker (`03)`), so it no longer reparses as a list.
